A semantic magazine article demonstrating fluid, accessible web typography.

Features

CSS custom properties for type and spacing

Fluid clamp() sizing with rem and vw

Readable 70ch article width

Optical text trimming with fallbacks

No breakpoint-based font sizing

Browser zoom and user font settings preserved

Run

Open index.html in a browser, or run:

python3 -m http.server 8000

Then visit http://localhost:8000.
